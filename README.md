# ClayPath Lab

陶土・磁器土ペースト用の、ブラウザで動くスライサー。STL（回転体に近い形）を Vase モード（らせん）で切り、**太さ（E）・速度（F）・XY のうねり**で経路に表情をつけ、3D でプレビューして G-code を書き出します。

**使う：** https://kanejun06.github.io/claypath-lab/

**説明書：** [docs/](docs/README.md)（ClayLine／ClayPath／ClayMorph の使い方と、機械の設定・教員モード・自分の機械への合わせ方）

インストール不要。ブラウザで開くだけで動きます（three.js を CDN から読むので、ネット接続が要ります）。3 つのツールは機械の設定・底面の充填・切り替えタブを `shared/` で共有しているので、手元で使うときは次のどちらかにしてください。

- **1 枚で動く版**（`standalone/`）：`shared/` の中身を埋め込んだ HTML です。ファイル 1 枚を保存して開くだけで動きます（学生への配布や改造用にも）
  - [claypath-lab.html](https://kanejun06.github.io/claypath-lab/standalone/claypath-lab.html)／[clayline-lab.html](https://kanejun06.github.io/claypath-lab/standalone/clayline-lab.html)／[claymorph-lab.html](https://kanejun06.github.io/claypath-lab/standalone/claymorph-lab.html)（開いてから「名前を付けて保存」）
  - 3 枚を同じフォルダに置けば、タブでの切り替えもそのまま使えます
- リポジトリをフォルダごと保存する（GitHub の「Code → Download ZIP」）

`standalone/` は `python3 tools/build-standalone.py` で作り直します。ツールや `shared/` を変えたら、これを実行してから一緒にコミットしてください（`standalone/` を直接編集しない）。STL はブラウザの中だけで処理され、どこにも送信されません。

## 使い方

1. 「STLを読み込む」かドラッグ＆ドロップで STL を入れる（「サンプル（φ40×100）」で試せます）
2. 左のパネルで変調をつける。各系統は見出しのチェックで ON/OFF
   - **太さ E**：高さ方向のカーブ（5 点をドラッグ、ダブルクリックで戻す）と周方向の揺れ
   - **速度 F**：速度倍率の高さ方向のカーブ、周方向の揺れ（基準の印刷速度・初層速度は右下 G-code の「押出・開始/終了コードの設定」にあり、`?teacher` で変更可）
   - **XY**：輪郭のうねり（振幅・波数・ねじれ・波形）
3. プレビュー右上の「推定・判定」で、出力時間・線幅・押出レートとオーバーハングなどの警告を確認する。「▶ 再生」でノズルの動きを時間どおりに見られます
4. 「保存」で `.gcode` を書き出し、SD カードへ

ほかに、白黒の画像を巻き付けて凹凸をつける「画像のバンプ」、口の縁を斜め・波・注ぎ口にする「口の形」、斜めの壁ほど線を太くする「傾斜補正」、「作例を開く…」があります。詳しくは[説明書](docs/claypath.md)。

左パネル上の「設定を保存」（⌘S / Ctrl+S）で、設定と読み込んだ STL をまとめて 1 つのファイル（.json）に保存し、「読み込み」で元に戻せます（STL を入れたくないときは「STLも保存」を外す）。「リセット」は 2 回押すと最初の値に戻ります。設定の変更は ⌘Z / Ctrl+Z で元に戻し、⇧⌘Z / Ctrl+Y でやり直せます。

## ClayLine Lab（SVG から描く）

**使う：** https://kanejun06.github.io/claypath-lab/svg/

SVG の線を層ごとに積み上げて、トレイや格子のような形をつくるツールです。

1. 「SVGを読み込む」かドラッグ＆ドロップで SVG を入れる（「サンプル（波線トレイ）」で試せます。「サンプルSVGを保存」で Illustrator のひな形にできます）
2. 「枠」で形を選ぶ。**角・丸**ではアプリが絵の中心に枠をつくり、はみ出た線を切ります（SVG には模様だけを枠より大きめに描く。層ごとに回すなら、枠の一番遠い所まで届く円を覆う大きさに）。**SVGの閉じた形を使う**では、開いた線が「壁の線」、閉じた形（四角・円）が「枠」になります。width が mm ならそのまま、px なら「1px＝1pt（Illustrator）」で換算します
3. 「層」で高さと底面の層数を決める。「層ごとの回転」で、模様を1層ずつ回せます（一方向・往復・交互）。「経路」で描く順序とつなぎ方を選ぶ。既定の「枠に沿って押出」は、線の端どうしを枠の上でつないで、持ち上げ移動なしの一筆にします
4. 大きさは「拡大率（全体）」と「横 × 縦の倍率」、線の太さは「太さ」の「壁の線の太さ」「枠の太さ」（押出量で変える）で調整できます
5. 「推定・判定」で、交差（盛り上がる所）・接点（セルを閉じる所）・持ち上げ回数を確認してから保存

左パネル上の「設定を保存」で、設定と読み込んだ SVG をまとめて1つのファイル（.json）に保存し、「読み込み」で元に戻せます。「リセット」は2回押すと設定が最初の値に戻ります（SVG はそのまま）。設定の変更は ⌘Z / Ctrl+Z で元に戻し、⇧⌘Z / Ctrl+Y でやり直せます（⌘S / Ctrl+S で設定を保存）。

文字はアウトライン化してから読み込んでください（text・use・画像は読みません）。

## ClayMorph Lab（断面を変えていく器）

**使う：** https://kanejun06.github.io/claypath-lab/morph/

下の断面から上の断面へ、層ごとに形を少しずつ変えていく器（例：底は丸、口は星形／花びら形）を、Vase モードの一筆で描くツールです。STL は要りません。

1. 「下の断面」「上の断面」で形を選ぶ（円・花びら・星・多角形・楕円）。「SVGを読み込む」で、SVG の閉じた形（一番大きいもの）も使える。数・深さ（内側の比率）・角の丸み・向きを調整し、それぞれの大きさを外接円の直径で決める
2. 「高さ方向」で高さと最大径を決める。🔗 を押している間は、どちらかを変えるともう一方と輪郭全体が同じ比率で変わる（±10% はいつも全体を拡大・縮小）
3. 「横から見た輪郭」で、正面から見た壁の線を点のドラッグで整える（縦横同じ縮尺。空いている所をダブルクリックで点を足し、点をダブルクリックで消す。一番上の点を上下に動かすと高さが変わる）。「左右対称」「上下対称（左右の点を同じ高さに）」を外すと、傾いた器や片側だけふくらむ器になる。赤い線はオーバーハング警告の角度を超えている所
4. 「形の変化」のカーブで、下の形から上の形へどの高さで変わるかを決める。「ねじれ」で口までに回す角度を足せる。点の対応は「自動」のままでよい（放射状の形は中心からの角度、C 字のように中心から見て輪郭が重なる形は周の長さで混ぜる）
5. 「画像のバンプ」「口の形」「傾斜補正」は ClayPath Lab と同じ。G-code 欄の「STL」で、器の形を 1 つの閉じた立体の STL として書き出せる（Cura の Vase モードでスライスできる）。「作例を開く…」に 6 つの作例
6. 底面の充填は、同心らせんで埋めきれない形（くびれや凹みのある形）では自動で「外周＋往復」に切り替わる。らせんへのつなぎ、太さ・速度・XY の変調、推定・判定、G-code の書き出しは ClayPath Lab と同じ

「設定を保存」（⌘S / Ctrl+S）で、設定・輪郭・読み込んだ SVG をまとめて 1 つのファイル（.json）に保存し、「読み込み」で元に戻せます。「リセット」は 2 回押すと最初の値に戻ります（読み込んだ SVG は残る）。設定の変更は ⌘Z / Ctrl+Z で元に戻し、⇧⌘Z / Ctrl+Y でやり直せます。

## 前提としている機械

神戸芸術工科大学の **SYNO-SOURCE-3040**（空圧タンク＋スクリュー押出、ノズル 1.5 mm）で実機確認した値を、3 つのツールで共有しています（`shared/printer.js`）。

| 項目 | 値 |
|---|---|
| ノズル／線幅／層高 | 1.5 mm／1.5 mm／0.9 mm |
| フィラメント径（E の換算用）／押出倍率 | 2.2 mm／0.85 |
| 初層の押出倍率 | 0.85（1 層目とスカートだけ、押出倍率にさらに掛ける。初層のダマ対策として実機で決めた値） |
| 底面の充填の線間隔（既定・変更可） | 線幅の 1.25 倍（1.0 では 2 層目にダマが出た） |
| 傾斜補正（既定・変更可） | オン、上限 ×1.2（傾いた壁の厚みを線幅にそろえる。30° で ×1.15） |
| 外周速度／初層速度／移動速度 | 18 mm/s／18 mm/s／60 mm/s |
| Z の移動速度／移動時の持ち上げ | 40 mm/s／1 mm |
| リトラクト | 1 mm（30 mm/s） |
| スカート | 1 周・オフセット 6 mm |
| ベッド中心 | X150 / Y150（開始コードの `G92 X-15 Y-30` と合わせて実機で位置確認済み） |
| 造形範囲 | 300 × 300 × 400 mm |

**機械の設定は、学生の画面ではロックされています**（画面上部に 🔒 と表示）。設定ファイルを読み込んでも、機械の値はファイルの中身ではなくこの値になります。試し刷りなどで変えたいときは、URL の末尾に `?teacher` を付けて開くと（例：`https://kanejun06.github.io/claypath-lab/morph/?teacher`）、そのタブだけ変更できます。再読み込みすると元の値に戻ります。学生が使う値そのものを変えるときは、`shared/printer.js` を書き換えてください。ロックは誤操作を防ぐためのもので、アクセス制限ではありません。

空気圧・土の配合・ベッドの材質は G-code の外で決まるので、ここでは扱いません。ほかの機械で使うときは、必ず自分の機械に合わせてください。**出力した G-code は、自分の機械で安全を確かめてから使ってください。**

## 授業での位置

PD応用実習Ⅱ（3 年後期・セラミック 3D プリント課題）の「形をつくる三つの方法」の 2 番目として使います。ClayLine Lab は SVG から形をつくる方法、ClayMorph Lab は断面の組み合わせから形をつくる方法として使います。
