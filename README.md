# ClayPath Lab

陶土・磁器土ペースト用の、ブラウザで動くスライサー。STL（回転体に近い形）を Vase モード（らせん）で切り、**太さ（E）・速度（F）・XY のうねり・Z の波打ち**で経路に表情をつけ、3D でプレビューして G-code を書き出します。

**使う：** https://kanejun06.github.io/claypath-lab/

インストール不要。HTML 1 枚で動きます（three.js を CDN から読むので、ネット接続が要ります）。STL はブラウザの中だけで処理され、どこにも送信されません。

## 使い方

1. 「STLを読み込む」かドラッグ＆ドロップで STL を入れる（「サンプル（φ40×100）」で試せます）
2. 左のパネルで変調をつける。各系統は見出しのチェックで ON/OFF
   - **太さ E**：高さ方向のカーブ（5 点をドラッグ、ダブルクリックで戻す）と周方向の揺れ
   - **速度 F**：初層速度、高さ方向のカーブ、周方向の揺れ
   - **XY**：輪郭のうねり（振幅・波数・ねじれ・波形）
   - **Z**：層の波打ち
3. プレビュー右上の「推定・判定」で、出力時間・線幅・押出レートとオーバーハングなどの警告を確認する。「▶ 再生」でノズルの動きを時間どおりに見られます
4. 「保存」で `.gcode` を書き出し、SD カードへ

## 前提としている機械

神戸芸術工科大学の **SYNO-SOURCE-3040**（空圧タンク＋スクリュー押出）で実機確認した値が初期値です。

| 項目 | 初期値 |
|---|---|
| 層高／線幅 | 0.9 mm／1.5 mm |
| フィラメント径（E の換算用） | 2.2 mm |
| 押出倍率 | 0.85 |
| 外周速度／移動速度 | 18 mm/s／60 mm/s |
| ベッド中心 | X150 / Y150 |

開始・終了コードと押出の設定は「押出・開始/終了コードの設定」で変えられます。ほかの機械で使うときは、必ずここを自分の機械に合わせてください。**出力した G-code は、自分の機械で安全を確かめてから使ってください。**
