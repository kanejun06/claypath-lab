# 説明書：ClayLine Lab／ClayPath Lab／ClayMorph Lab

陶土・磁器土のペースト押出 3D プリンタ（**SYNO-SOURCE-3040**）で、経路（G-code）を自分で設計するためのブラウザツール 3 つの説明書です。インストール不要で、ブラウザで開くだけで使えます。

| ツール | 何から形をつくるか | 向いているもの | 開く |
|---|---|---|---|
| [ClayLine Lab](clayline.md) | SVG の線（描いた線がそのままノズルの通り道） | トレイ・格子・敷物など低く平たいもの | https://kanejun06.github.io/claypath-lab/svg/ |
| [ClayPath Lab](claypath.md) | STL（Fusion などでつくった回転体に近い形） | 筒・器。形はそのままに表面の表情を経路でつける | https://kanejun06.github.io/claypath-lab/ |
| [ClayMorph Lab](claymorph.md) | 下の断面・上の断面・横から見た輪郭（CAD 不要） | 断面が高さとともに変わる器・花器 | https://kanejun06.github.io/claypath-lab/morph/ |

3 つは画面上部のタブで切り替えられます。並びは授業で紹介する順です。

1. **Line**：線を描く＝経路を描く。線幅・層・つなぎ・持ち上げなど、機械の振る舞いがいちばん直接見える
2. **Path**：与えられた形（STL）を、経路の変調（太さ・速度・XY・Z）で加工する。「形」と「経路」を分けて考える
3. **Morph**：断面と輪郭の組み合わせで形そのものを生み出す

## 前提

- 機械：SYNO-SOURCE-3040（空圧タンク＋スクリュー押出、ノズル 1.5 mm、加熱なし、SD カード運用）。神戸芸術工科大学で実機確認した値が入っています
- ブラウザ：Chrome／Edge／Safari の新しいもの。3D 表示（three.js）を CDN から読むので、ネット接続が必要です
- **出力した G-code は、自分の機械で安全を確かめてから使ってください。** 特にほかの機械や別のノズルで使うときは、[共通の使い方](common.md#自分の機械に合わせる) を読んで機械の設定を合わせてください
